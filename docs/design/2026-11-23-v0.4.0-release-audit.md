## 🟡 Warnings (should review)

- **W1** Release gate — the macOS test run (ADR-0022) has not been done for this commit. The suite ran on linux/arm64 only; darwin/arm64 is cross-built. The new code is platform-neutral (flag parsing, string building, two JSON fields), so a failure is unlikely, but ADR-0022 makes the run a condition of the release.
- **W2** staticcheck and govulncheck did not run in this session (the session's permission check refused `go run` of external tools). No new module was added since `v0.3.2` (`go.mod` unchanged), so govulncheck in the release workflow covers the same module set; staticcheck is not run anywhere in CI, so run `staticcheck ./...` locally before the tag.
- **W3** `README.md:68`, `CHANGELOG.md:27`, `docs/adr/0024-claude-desktop-extension-bundle.md:49`, `docs/agents/environment.md:77` — they say the bundle's `NAME` is the server name Claude Desktop shows. In the live check of 2026-11-23 Desktop named the server after `display_name`, `memctl (albdocs)`, and the tools became `memctl__albdocs___*` instead of `albdocs__*`. Either the docs say so, or `scripts/mcpb-build.sh` sets `display_name` to `NAME` so the server keeps the name of the config entry it replaces (a decision for the maintainer; it also decides what tool names the agent sees).
- **W4** `docs/design/solution-design.md` — ADR-0024 (Accepted) is not in the design: "Deployment and config" and the Amendments table say nothing of the extension or `make mcpb`, although the design is the source of truth (CLAUDE.md).
- **W5** Agent guides — `docs/agents/tools.md` ("Authoring the tool text") lists six parts of a description and does not mention the scope line that ADR-0025 appends at run time (amending ADR-0013). `CLAUDE.md`'s layout block has no `mcpb/` folder (ADR-0024).
- **W6** `cmd/memctl/scope.go:29` — the "one line" rule rejects only Unicode category Cc. U+2028 LINE SEPARATOR and U+2029 PARAGRAPH SEPARATOR (categories Zl, Zp) pass and render as line breaks in some clients; invisible format characters (Cf, such as U+202E or U+200B) pass too. The code matches SPEC-0011 R3 as written, so this is a spec gap: the scope comes from the person's own configuration, so the risk is low, but "one line" is not fully enforced.

extension takes its name as its display name.

  Desktop names the server and the tool prefix after it; ADR-0024, README,

  Amendments row).

  layout shows `mcpb/`.
- W6 — fixed: SPEC-0011 R3 amended; a scope with a line or paragraph separator
  (Zl, Zp) or an invisible format character (Cf) is refused, with tests.
- N1 — fixed: this report is in the design index.
- W1, W2 — open, for the maintainer before the tag: the macOS test run
  (ADR-0022) and `staticcheck ./...`.
